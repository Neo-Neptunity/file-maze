# ファイル迷路

壁にファイル名が刻まれた迷路です。新しいファイルから、長く開いていないファイルまで、分かれ道だらけの迷路を抜けると、コインがもらえます。

**ファイルは変えません。** 読むのは名前・種類・大きさ・更新日時だけで、中身は読みません。通信もしません。

[explorer_plus](https://github.com/Neptunity-git/explorer_plus) の MOD です。`neo.file-maze` 2.0.0。フォルダと関係ないビューなので、どのフォルダを開いていても使えます。

## 遊びかた

- はじめの画面で、クイックアクセスのフォルダから、遊ぶ場所を選びます。
- 迷路は、ふつうに作られます。分かれ道も行き止まりもあります。壁には、そのフォルダの中のファイル名が刻まれています。
- 上の帯に、いまいる場所の道すじ（フォルダの順）が出ます。歩くにつれて、フォルダが連続して変わります。
- 手がかりを使うと、正解の道すじの一部が光ります。
- ゴールすると、迷路の長さに合わせて、コインがもらえます。コインは、ショップで使えます。

## 入れ方

1. [Releases](https://github.com/Neo-Neptunity/file-maze/releases) を開き、いちばん新しい版の zip（`neo.file-maze-版.zip`）をダウンロードします。「Source code」ではなく、自分で付けた zip のほうです。
2. explorer_plus のホームの「MOD」の欄で「＋ MOD を入れる（zip）」を押して、zip を選びます。解凍はしません。
3. 確認の画面の「このビューが使う情報」を読んで、よければ入れます。

## 使う情報

| 使う情報 | 使いみち |
|---|---|
| `tree` | 選んだフォルダから下の階層を読んで、迷路にする |
| `quickAccess` | はじめの画面に、クイックアクセスのフォルダを出す |
| `size` `modified` | 大きさと更新日時を読む。新しいファイルから古いファイルへ、ゴールを決める |

## 設定

歩く速さ（ゆっくり / ふつう / はやい）・マウスの押しっぱなしでも動く・調べる階層の深さ（2〜5。標準は 4）。

## 作りかた

- [dev/](dev/)：自動の試験と、画面を撮る道具。説明は [dev/README.md](dev/README.md)。そこに書かれたコマンドは、作者の置き場所から流す書き方です。このリポジトリでは、先頭の `file-maze/` を外して読んでください。

```
node dev/unit.mjs
```

Node.js だけで動きます。`dev/browser.mjs` は Edge か Chrome が要ります。
